## 🚀 Overview

This repository contains the source code for my personal portfolio. It's designed to showcase my journey as a Computer Science student, highlighting my projects in Web Development and AI/ML, my technical skills, and professional certifications.

### ✨ Key Features

- **⚡ Blazing Fast**: Built with Vite for near-instant hot module replacement (HMR).
- **📱 Fully Responsive**: Optimized for all screen sizes (Mobile, Tablet, Desktop) using CSS Flexbox and Grid.
- **🎭 Smooth Animations**: Integrated with [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) for a dynamic browsing experience.
- **🎨 Modern UI/UX**: Professional dark-themed design with curated typography and hover effects.
- **📂 Component-Based**: Modular architecture using React functional components for maintainability.

## 🛠️ Tech Stack

### Frontend
- **Framework**: [React 19](https://reactjs.org/)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/B-koushik-09/react-portfolio.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd react-portfolio
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Start the development server**
   ```bash
   npm run dev
   ```
